# Programmer le SONOFF ZBDongle-P

Le [guide d'installation et de mise à jour](firmware/installation.md) décrit l'utilisation du [Web Flasher](https://rafal83.github.io/SONOFF-ZBDongle-P/), la sauvegarde préalable, le choix du débit et les vérifications après écriture.

Pour remettre une version sauvegardée, suivre le [guide de restauration](firmware/restauration.md). Le stockage Zigbee actuel et ses compteurs sont conservés.

Les builds et tests n'ouvrent aucun port série. Une intervention matérielle se lance explicitement, après arrêt de Zigbee2MQTT.
